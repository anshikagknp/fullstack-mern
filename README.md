## Notes

- Files within each folder are numbered in the order they should be studied.
- Filenames are descriptive of the topic they cover (e.g. `07-position-fixed.html`, `09-modal.html`).
- Demo files are self-contained and can be opened directly in a browser, aside from ones that rely on the shared `images` or `multimedia` folders.
- `MongoDBQueries.js` is a reference script of commands, not an executable file — it is meant to be run inside the MongoDB shell.

## Getting Started

Clone the repository and open any `.html` file directly in your browser, or open the folder in an editor to browse through the notes topic by topic.
